# 第5步：断言设计

冻结评估集 baking-v1.0｜制作日期 2026-10-06｜200条合成样本

所有样本检查未知字段/值、幻觉条件和最小Patch。条件字段检查field_exact及operator_correct；按内容追加hard_soft/negation/allergen、替换/保持/清除、全文/排序/未映射断言。
tags由derive_tags生成，不由模型或手工标签决定。所有断言参数及Gold支持性通过现有合同校验。
