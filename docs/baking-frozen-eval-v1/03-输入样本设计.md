# 第3步：输入样本设计

冻结评估集 baking-v1.0｜制作日期 2026-10-06｜200条合成样本

来源：本次直接编写的合成输入，不是客户日志，也未使用生成API。
总计200条。多轮用给定前态测试一次转移，不向模型传完整对话；同一前态可作为对照控制。
用户原话均不重复。审核关注用途/形态、硬软、口味/过敏、数值/相对偏好的边界。
